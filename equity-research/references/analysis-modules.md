# 九大模块分析细则与评分 Rubric

供 Step 4 使用。每个模块的结论都要能追溯到数据；评分必须锚定下方 rubric，禁止"感觉很优秀"式打分。

## M1 公司概况

- 基本信息：名称、代码、上市地与时间、市值、控股股东、实控人、核心管理层（来源：年报封面与"公司基本情况"章节、东方财富 F10）
- **"这家公司靠什么赚钱"：3~5 句普通人能懂的话**【判断】
- 收入结构：按产品/服务/地区/客户的占比与趋势（年报经营讨论与分析）
- 股本与筹码：总/流通股本、质押比例、限售解禁时间表、近一年增发/回购

## M2 行业与同业

- 生命周期判断：高速增长 / 成熟 / 周期 / 衰退（依据行业增速数据，注明来源年份）
- 市场规模与增速：当前规模、历史增速、未来预期
- 竞争格局：龙头、市占率、CR3/CR5、新进入者威胁、替代品
- 上下游：对上游议价力、对下游议价力、原材料风险、客户集中度（年报前五客户占比）
- 政策：支持 / 限制 / 监管风险 / 潜在变化
- **同业对比表**：选 3~5 家可比公司，对比营收/净利增速、毛利率、ROE、PE/PB——判断公司在行业中的真实位置，同时为相对估值提供锚
- 输出：行业前景评分 1~10 + 理由

### 行业前景评分锚点

| 分 | 表现 |
|---|---|
| 9–10 | 空间大且确定：长期增速 >15%，格局清晰，政策友好 |
| 7–8 | 稳健增长 5%~15% |
| 5–6 | 成熟平稳 0~5%，或高增长但格局混乱/政策不确定 |
| 3–4 | 衰退期，或强周期顶部下行 |
| 1–2 | 技术替代/政策打压下的萎缩 |

## M3 商业模式

必答八问：钱从哪来 / 主要成本 / 为何有毛利 / 客户是谁 / 客户为何不换 / 一次性还是持续收入 / 有无提价能力 / 是否需要持续大额资本投入。

输出：商业模式评分 1~10、优势清单、缺陷清单。

### 商业模式评分锚点

| 分 | 表现 |
|---|---|
| 9–10 | 高毛利 + 高复购 + 低资本开支 + 强定价权（如顶级品牌消费品） |
| 7–8 | 上述多数成立，个别短板 |
| 5–6 | 赚钱但依赖持续投入或竞争挤压（制造/项目制） |
| 3–4 | 低毛利 / 强周期 / 重资本 / 客户高度集中 |
| 1–2 | 增长靠烧钱且单位经济为负 |

## M4 财务质量（用 scripts/calc.py 输出，禁止手算）

检查清单：

- **成长**：营收/净利润/扣非净利润增速与 CAGR；营收 vs 利润增速背离必须解释（费用率？减值？税率？）
- **盈利**：毛利率、净利率、ROE/ROA 及稳定性；杜邦分解判断驱动因素（利润率 / 周转 / 杠杆）
- **利润质量红旗**：经营现金流/净利润连续 <0.8 → ⚠️ 利润质量风险；扣非与净利润长期背离 → 依赖非经常性损益
- **偿债**：资产负债率、有息负债、利息保障倍数、流动/速动比率 → 财务风险 低/中/高
- **资产质量红旗**：商誉/净资产 >20%；应收增速长期 > 营收增速；存货异常堆积——逐项提示
- **现金流**：五年 FCF 合计是否为正；上市以来累计分红 vs 累计募资

### 财务质量评分锚点

| 分 | 表现 |
|---|---|
| 9–10 | 5年 ROE≥15% 且稳定、OCF/净利润常年 ≥1、扣非占比 ≥90%、低有息杠杆、商誉/净资产 <10% |
| 7–8 | ROE 12%~15% 或略有波动、OCF/净利润 ≥0.8、个别年份有瑕疵 |
| 5–6 | ROE 8%~12%、现金流一般、部分依赖杠杆 |
| 3–4 | ROE <8% 且下滑、OCF/净利润 <0.6、应收/存货堆积 |
| 1–2 | 亏损、现金流持续为负、高杠杆、审计瑕疵（同时触发一票否决检查） |

## M5 成长性（未来 3~5 年，三情景）

依据：行业空间、市占率、新产品/新市场、产能、技术、海外扩张。

- 悲观 / 基准 / 乐观三情景，**每条写明依据**，标注【事实】或【假设】
- 三情景增速同时供 DCF 使用——估值参数必须与成长情景保持一致，不得两边自相矛盾

### 成长性评分锚点

| 分 | 表现 |
|---|---|
| 9–10 | 基准情景利润增速 >15%，且有产能/订单/行业空间支撑 |
| 7–8 | 基准 8%~15% |
| 5–6 | 基准 3%~8% |
| 3–4 | 基准 0~3%，或依赖单一不确定变量 |
| 1–2 | 基准情景负增长 |

## M6 护城河

维度按公司实际选择（不必全填）：品牌、成本、网络效应、转换成本、技术、专利、渠道、规模、牌照/资源。每项 0~5 分，**必须给事实证据 + 来源 [n]**。

总分映射：`各维度得分之和 / (5 × 适用维度数) × 10`，四舍五入到 0.5。

### 护城河评分锚点（映射后）

| 分 | 表现 |
|---|---|
| 9–10 | 多条宽阔护城河且相互强化；定价权可验证（提价不掉量，有数据） |
| 7–8 | 一条宽护城河或多条窄护城河 |
| 5–6 | 有优势但可被侵蚀 |
| 3–4 | 优势微弱，主要靠先发或客户关系 |
| 1–2 | 无护城河，同质化竞争 |

禁止"因为公司很优秀，所以 5 分"。

## M7 管理层与公司治理

- 管理层：任期、历史业绩兑现度（对比 3 年前指引 vs 实际）、股权激励行权条件、高管持股与增减持、薪酬
- 资本配置：并购记录与商誉结果、分红率、回购、增发摊薄
- 治理核查清单（逐项给结论）：关联交易、大股东资金占用、违规担保、监管处罚与立案、审计意见、会计政策变更、高管频繁变动、大股东频繁减持

### 管理层与治理评分锚点

| 分 | 表现 |
|---|---|
| 9–10 | 长期业绩兑现、分红/回购记录良好、治理核查全清白 |
| 7–8 | 总体良好，个别小瑕疵且已披露解释 |
| 5–6 | 记录平淡或公开信息不足 |
| 3–4 | 频繁减持、并购失败史、问询函多 |
| 1–2 | 触发一票否决项 |

## M9 风险与反向论证

- ≥5 项风险，每项标注：影响程度（高/中/低）+ 发生概率 + **可观察的预警指标**（例如"毛利率连续两季下滑 2pct"）
- Bear Case：假设未来 5 年表现很差，为什么？≥5 条失败路径，指明最值得警惕的 1 条
- Bull Case：远超预期的可能原因
- 多空对照表 + 回答"目前哪一方证据更充分"

## 一票否决清单（Step 7 首先检查，命中任一 → 🔴）

- 审计报告为非标意见（保留/无法表示意见/否定）
- 公司或实控人因财务造假被立案或处罚坐实
- 大股东质押 >50% 叠加资金占用或违规担保
- 资不抵债或面临退市风险警示
- 数据完备率 <70%（输出"数据不足"，不给任何积极结论）
