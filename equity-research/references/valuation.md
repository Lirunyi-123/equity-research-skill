# 估值方法与特殊行业规则

供 Step 5 使用。估值回答第二个问题：**现在这个价格值不值得买**。必须多方法交叉，输出区间而非单点。

## 1. 相对估值

| 指标 | 公式 | 适用 | 注意 |
|---|---|---|---|
| PE(TTM) | 市值 / 滚动12个月净利润 | 盈利稳定的公司 | 周期股失真；用扣非口径复核 |
| PE(静态) | 市值 / 最近年报净利润 | — | 半年内适用，过期改 TTM |
| PB | 市值 / 净资产 | 重资产、金融 | 必须结合 ROE 看 |
| PS | 市值 / 营收 | 亏损、高成长公司 | 必须结合净利率看 |
| PEG | PE / 盈利增速(%) | 成长股 | 增速用未来 3~5 年预期，标【假设】 |
| EV/EBITDA | (市值+有息负债−货币资金)/EBITDA | 跨杠杆比较、重资产 | 剔除资本结构差异，同业对比更好用 |
| 股息率 | 近12个月每股分红 / 现价 | 成熟分红公司 | 结合派息可持续性（FCF 是否覆盖） |

同业对照：与 M2 选出的可比公司对照，判断相对贵贱。**同业整体高估时相对估值失真**（板块泡沫），必须说明并依赖历史分位与 DCF。

## 2. 历史分位

- 当前 PE(TTM)/PB 在近 5 年（可得 10 年则优先 10 年）序列中的中位数与分位
- 数据来源：行情平台的历史估值页面；无法取得完整序列时用当前值 vs 5 年高低点估算，并注明口径
- **低分位 ≠ 低估**：基本面恶化的公司估值中枢会永久下移（低 PE 陷阱）；分位只反映市场给它的估值区间变化，必须结合质量分交叉判断

## 3. DCF（scripts/dcf.py）

### 基期 FCF
用近 3 年平均 FCF 做正常化基期；若有明显一次性冲击（疫情、大额减值、并购并表），剔除并注明【假设】。

### WACC 取值
简化公式：WACC ≈ 无风险利率 + β × 股权风险溢价
- 无风险利率：10 年期国债收益率（检索最新值，标【事实】+来源）
- 股权风险溢价：A 股取 6%~7%
- β：不确定时取 1.0，或按行业取 0.8~1.3
- 合理区间通常 7%~11%；敏感性矩阵必须覆盖该区间

### 永续增长率 g
0~3%，不超过长期名义 GDP 增速。**严禁 g ≥ WACC**（脚本会拒绝计算该格）。

### 三情景
- 悲观/基准/乐观的显性期增速差异要明显（如 0% / 8% / 15% 量级），且与 M5 成长性三情景一一对应
- 输出每股价值区间 = 悲观 ~ 乐观；**中枢取基准情景**

### 敏感性矩阵
脚本自动输出（基准情景路径，WACC × 永续增长率）。解读规则：若矩阵角点值相差 >2 倍，说明估值对参数高度敏感，结论必须保守，并在报告中写明"估值不确定性高"。

## 4. 特殊行业规则（优先级高于通用方法）

| 行业 | 用什么 | 禁止什么 |
|---|---|---|
| 银行 | PB-ROE 框架（ROE 高且稳定者 PB 中枢高）+ 股息率 | DCF |
| 保险 | PB / 内含价值(EV) | 直接用 PE 下结论 |
| 证券、强周期（钢铁/化工/航运/养殖） | 正常化盈利 PE（取周期中枢利润）、EV/EBITDA | 用景气顶点利润算 PE；把低 PE 当低估信号 |
| 亏损 / 早期成长 | PS、EV/S、单位经济模型（UE） | PE、PEG |
| 地产 | PB 与 NAV 折价 | 单看 PE |

## 5. 安全边际与交叉验证

安全边际 = 1 − 现价 / 内在价值中枢（基准情景）：

| 安全边际 | 判断 |
|---|---|
| ≥30% | 明显低估 |
| 10%~30% | 合理偏低 |
| −10%~10% | 合理 |
| −30%~−10% | 偏高 |
| <−30% | 明显高估 |

DCF 结论必须与历史分位、同业对照**交叉验证**；方法之间矛盾时，取更保守的结论，并解释分歧来源（通常是增长或折现率假设差异）。

## 6. 输出纪律

- 一律区间 + 假设说明；禁止伪精确单点（如"内在价值 = 137.52 元"）
- 所有参数标【假设】，写明取值依据
- 数据不足（缺 FCF 历史 / 缺行情）→ 标注后只做相对估值，**不得硬凑 DCF**
- 银行等不适用 DCF 的行业，估值章节写明方法替换的原因
